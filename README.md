# Auth-Cookies

    Программа для аутентификации на серверах, использующих "cookies-auth". Полученные cookie-файл сохраняется в отдельной директории под своим именем в .json формате. После истечения срока действия cookie-файла на сервере - он автоматически заменяется на новый.
    При вызове функции auth() используйте создание экземпляра класса:
    obj = AuthCookies()
    obj.auth(url_web= 'url_size')
    При вызове функции auth() укажите url-адрес ('url_size') страницы входа с аутентификацией.

Необходимые программы:
python>3.11
requests==2.34.2

Для корректной работы укажите:
# url адрес страницы аутентификации
self.auth_url = 'url_auth'
# Имя пользователя
self.user_web = 'user'
# Пароль
self.password_web = 'password'
# Если соединение происходит через прокси-сервер укажите их в словаре, пример: {‘http’: ‘foo.bar:3128’, ‘http://host.name’: ‘foo.bar:4012’}, если proxy_url нет - ''
self.proxy_url = ''
# Укажите директорию для хранения cookie-файла
self.directory = <"адрес директории для хранения cookie">
# Укажите имя cookie-файла
self.filename = <'название файла с cookies'>
# Максимальное число повторных попыток авторизации - можно изменить
self.max_retries = 3
# Задержка между повторными подключениями в секундах - можно изменить, при плохом интернете увеличьте
self.retry_delay = 1
